# سایت معرفی مهندس محمد پیشه‌زاری (نقشه‌بردار)

HTML + CSS + JavaScript خالص، بدون کتابخانه و بدون بیلد. فایل `index.html` را باز کنید.

- پس‌زمینه سه‌بعدی با Canvas: سطح زمین توری، ابر نقطه، منحنی میزان، پهپاد با دوربین و نقاط کنترل BM
- دوربین با اسکرول مثل فیلم در مسیر پرواز می‌کند
- RTL، ریسپانسیو، پشتیبانی `prefers-reduced-motion`
- فونت Vazirmatn از Google Fonts (بدون اینترنت از Tahoma استفاده می‌شود)

## پیش از انتشار جایگزین کنید
شماره تلفن، ایمیل، آمار (۴۰+ پروژه، ۲ سانتی‌متر)، نمونه‌پروژه‌ها و مختصات HUD نمایشی هستند.
کد و طراحی از نو نوشته شده و از هیچ قالب یا دارایی دیگری کپی نشده است.

## تنظیمات نهایی
- لینک اینستاگرام و روبیکا در فوتر (`index.html`) عمومی است؛ آیدی خودتان را جایگزین کنید. لینک تلگرام با شماره موبایل ساخته شده و فقط اگر شماره‌تان قابل جستجو باشد کار می‌کند؛ بهتر است `t.me/آیدی` بگذارید.
- نقشه گوگل با جستجوی آدرس ساخته شده؛ برای پین دقیق، در Google Maps گزینه Share ← Embed a map را بزنید و `src` ایفریم را عوض کنید.
- فرم تماس تمام مشخصات (نام، راه ارتباطی، موضوع، توضیح) را در یک پیام آماده به واتساپ ۰۹۹۲۱۶۵۴۹۸۵ می‌فرستد (شماره در `script.js`، ثابت `WA`).
- حالت روشن/تاریک با دکمه بالای سایت؛ پیش‌فرض تاریک است (در `<head>` فایل `index.html` قابل تغییر).
- عکس بخش «درباره»: فایل `assets/portrait.jpg` را با هر عکس مربع جایگزین کنید. پرامپت عکس در `assets/PORTRAIT-PROMPT.txt` است.
